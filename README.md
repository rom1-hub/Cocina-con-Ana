# Cocina con Ana

Web en español para descubrir recetas de todo el mundo y conocer servicios de chef a domicilio y para eventos.

## Estado actual
Primera estructura visual y técnica. No se han añadido recetas ni conectado un catálogo de datos.

## Tecnologías
- HTML
- CSS
- JavaScript puro
- Sin frameworks ni backend en esta etapa

## Archivos
- `index.html`: página principal, navegación, buscador y sección de servicios.
- `css/styles.css`: identidad visual azul claro, diseño responsive y componentes.
- `js/app.js`: navegación móvil, cambio entre modos de búsqueda e interacciones iniciales.

## Decisiones acordadas
- Público principal: España y América Latina; web en español.
- Las recetas podrán ser de cualquier parte del mundo.
- La prioridad de la página es descubrir recetas.
- Buscador con dos modos independientes:
  1. **Buscar por nombre:** no aplica filtros adicionales.
  2. **Buscar con filtros:** se perfeccionará progresivamente.
- No se han inventado recetas ni resultados.
- La sección de chef a domicilio y eventos es una estructura inicial; la zona de servicio y los datos comerciales quedan pendientes de definir.
- No incorporar nuevas funcionalidades sin consultarlo antes.

## Probar
Abrir `index.html` en un navegador. Las fuentes e imágenes decorativas se cargan desde servicios externos y requieren conexión.
